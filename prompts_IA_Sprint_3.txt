Os prompts abaixo foram usados como apoio durante o desenvolvimento da Sprint 3. A ideia foi usar a IA principalmente para tirar dúvidas, organizar as ideias, revisar o código e conferir se o que foi feito estava de acordo com o que a atividade pedia. Depois das sugestões, a equipe conferiu e fez as alterações necessárias no próprio projeto.


PROMPT 1 — ENTENDER O QUE A SPRINT PEDE

Estou fazendo a Sprint 3 do projeto Pelé Next Gen. Pelo que entendi, o Python precisa funcionar como a parte lógica do nosso MVP Visual. Me explica de um jeito simples o que a atividade está pedindo e o que eu preciso conferir no código para não esquecer nenhum requisito. Não faça o projeto inteiro.


PROMPT 2 — LIGAR AS TELAS AO PYTHON

Tenho um MVP Visual do Pelé Next Gen e preciso fazer a parte do Python acompanhar as telas. Como posso pegar cada ação que o usuário faz no protótipo e transformar isso em uma função no Python? Usa cadastro de atleta, listagem e dashboard como exemplos.


PROMPT 3 — ESCOLHER AS ESTRUTURAS DE DADOS

No nosso projeto vamos guardar informações de atletas, peneiras e avaliações. Me explica onde faz mais sentido usar listas, dicionários e matrizes e por quê. Quero uma estrutura simples que esteja dentro do que estamos aprendendo em Python.


PROMPT 4 — CONFERIR O CADASTRO

Já estou fazendo o cadastro de atleta do Pelé Next Gen. Quero conferir se os campos do terminal estão de acordo com o que aparece no MVP Visual. Me ajuda a montar uma lista do que preciso conferir e quais validações seriam importantes.


PROMPT 5 — VALIDAR OS DADOS

Me explica como posso usar if, elif e else para validar os dados que entram no cadastro e na avaliação de atletas. Quero exemplos simples para idade, notas e campos obrigatórios, para depois adaptar ao meu código.


PROMPT 6 — MONTAR O MENU

Preciso fazer um menu no terminal usando while e input para acompanhar a lógica do nosso MVP. No menu temos cadastro de atleta, peneiras, inscrição, avaliação, dashboard, ranking, comparador e desempenho. Me ajuda a organizar a lógica desse menu sem fazer o sistema inteiro por mim.


PROMPT 7 — SEPARAR O CÓDIGO EM FUNÇÕES

Meu código está começando a ficar grande e quero separar melhor as partes. Me explica como posso deixar cadastro, listagem, busca, avaliação e análise em funções diferentes e quando faz sentido usar parâmetros e return.


PROMPT 8 — FAZER OS CÁLCULOS DO DASHBOARD

No MVP Visual temos informações de desempenho dos atletas. Como posso identificar quais dados precisam ser calculados no Python e transformar esses cálculos em funções? Quero entender a lógica antes de colocar no código.


PROMPT 9 — COMPARAR O MVP COM O PYTHON

Quero conferir se o nosso Python realmente acompanha o MVP Visual. Me ajuda a montar uma tabela simples para eu comparar cada tela, o que o usuário faz nela, quais dados são usados e qual parte do Python faz essa função.


PROMPT 10 — REVISAR MEU CÓDIGO

Vou mandar meu código da Sprint 3. Quero que você procure problemas principalmente em listas, dicionários, matrizes, funções, menu, validações e na lógica geral. Em vez de reescrever tudo, me explica o que está errado e como eu posso corrigir.


PROMPT 11 — TESTAR O PROGRAMA

Quero testar o Pelé Next Gen antes de entregar. Monta alguns testes que eu possa fazer manualmente no terminal, incluindo cadastro correto, cadastro com erro, inscrição, avaliação, dashboard e saída do programa. Quero saber o resultado que deveria aparecer em cada teste.


PROMPT 12 — PROCURAR ERROS

Quero aprender a encontrar os erros do meu próprio código. Pensando em um programa com while, input, listas, dicionários, funções e if/elif/else, quais erros eu deveria procurar primeiro? Explica de uma forma que eu consiga testar sozinho.


PROMPT 13 — NÃO COMPLICAR O CÓDIGO

Revise a ideia do nosso projeto pensando no nível de uma atividade de faculdade em Python. Quero saber se tem alguma parte desnecessariamente complicada ou que usa algo que não precisamos. A solução deve mostrar que entendemos listas, dicionários, matrizes, funções, while, input e condicionais.


PROMPT 14 — CONFERÊNCIA ANTES DA ENTREGA

Me ajuda a montar uma checklist para revisar a Sprint 3 antes de entregar. Quero conferir o MVP Visual, o Python, os campos de cadastro, estruturas de dados, funções, menu, validações, cálculos, testes, README e o arquivo com os prompts.


PROMPT 15 — CONFERIR OS CRITÉRIOS

Quero conferir nosso projeto usando os critérios da Sprint 3: sincronia com o MVP Visual, estruturas de dados, modularização e lógica/execução. Não quero uma nota. Só quero saber o que devo procurar no nosso código para verificar se cada parte da atividade foi realmente atendida.
