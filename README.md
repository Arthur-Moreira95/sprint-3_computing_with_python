## Objetivo do projeto

O **Pelé Next Gen** tem como objetivo representar, por meio de um MVP Visual e de um programa em Python, uma solução voltada ao acompanhamento e à análise de atletas.

Na Sprint 3, o código Python funciona como o **gêmeo lógico do MVP Visual**. Isso significa que os fluxos realizados nas telas do protótipo devem possuir correspondência no terminal: cadastro, consulta/listagem, análise de desempenho e demais ações previstas pela equipe.

## Requisitos da Sprint 3

O programa deve:

1. Espelhar os fluxos do MVP Visual no terminal.
2. Utilizar listas, dicionários e matrizes de acordo com os dados exigidos pelas telas.
3. Possuir navegação por menu interativo com `while` e `input`.
4. Implementar validações com `if`, `elif` e `else`.
5. Separar as principais ações em funções independentes.
6. Executar sem quebras durante os fluxos previstos.
7. Calcular e apresentar no terminal os indicadores utilizados pelo MVP Visual.

## Relação entre o MVP Visual e o Python

| MVP Visual | Gêmeo lógico em Python |
|---|---|
| Tela de cadastro de atleta | Função de cadastro que solicita os mesmos campos |
| Lista/consulta de atletas | Função que percorre e apresenta os registros |
| Dashboard de desempenho | Função que calcula e exibe os mesmos indicadores |
| Regras de validação | Condicionais que impedem dados inválidos |
| Navegação entre telas | Menu interativo no terminal |
| Dados apresentados nas telas | Listas/dicionários/matrizes com a mesma estrutura lógica |

## Critérios considerados

- Sincronia com o MVP Visual.
- Evolução e uso adequado das estruturas de dados.
- Modularização por funções.
- Lógica, validações e execução sem erros.
